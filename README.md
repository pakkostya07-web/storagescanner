# Storage Scanner 💾

Легковесная утилита на Python для тех случаев, когда диск C: внезапно покраснел, а стандартный Проводник Windows упрямо отказывается показывать, какие именно папки сожрали всё свободное место.

Аналог WinDirStat и TreeSize, но написанный на Python: с удобным графическим интерфейсом, наглядными круговыми диаграммами и быстрым запуском.

## Зачем это нужно?

В Windows неудобно искать «тяжёлые» файлы: в свойствах каждой папки нужно копаться вручную, а встроенный поиск работает медленно.

Этот сканер решает проблему просто:

1. Пробегает по диску (или сразу по всему компьютеру) быстрым итератором `os.scandir`.
2. Сортирует найденное по типам: видео, игры, архивы, документы, код, образы дисков.
3. Рисует понятную диаграмму и выдает список папок-лидеров по весу.
4. Позволяет прямо из окна в один клик открыть нужную папку в Проводнике или подсветить конкретный файл-гигант, чтобы сразу решить, удалять его или оставить.

## Быстрый старт

### 1. Установка зависимостей

Нужен Python 3.8+ и библиотека `matplotlib` для отрисовки графиков:

```bash
pip install -r requirements.txt
```

### 2. Запуск программы

Вы можете запустить программу любым удобным способом:

- **Двойным кликом по `disk_scanner.pyw`** — запускает графический интерфейс сразу в оконном режиме (без лишнего чёрного окна командной строки).
- **Через терминал**:
  ```bash
  python disk_scanner.py
  ```

## Что внутри

- **Кнопка «🖥️ Весь компьютер»** — находит все ваши диски (C:, D:, флешки) и сканирует их разом. Удобно, если не помните, на какой именно накопитель улетела игра или распакованный архив.
- **Интерактивные графики**:
  - Слева: «пончик» распределения по категориям (сколько гигабайт ушло под видео, сколько под игры, архивы или документы).
  - Справа: наглядный горизонтальный топ-10 самых тяжёлых папок.
- **Топ-50 файлов-гигантов** — мгновенный список главных кандидатов на очистку с быстрым поиском/фильтром (можно вбить `.iso`, `.mkv` или `temp`).
- **Честный многопоточный режим** — интерфейс не виснет во время сканирования. Всегда видно, какая папка проверяется прямо сейчас, а сканирование можно остановить в любую секунду.
- **Консольный режим (CLI)** — если не хочется открывать графическое окно (например, на сервере или через SSH):

  ```bash
  # Просканировать все диски и сохранить картинку отчёта в storage_report.png
  python disk_scanner.py --cli --all

  # Проверить только конкретную папку
  python disk_scanner.py --cli --path "D:\SteamLibrary"
  ```

## Публикация в GitHub Releases

GitHub (как и браузеры) не позволяет напрямую прикреплять «голые» `.bat` файлы к релизам в целях безопасности.

Для публикации релиза используйте один из двух стандартных способов:

### Способ 1: Готовый ZIP-архив (Рекомендуется)

Выполните команду сборки релиза:

```bash
python build_release.py
```

Скрипт создаст готовый архив **`StorageScanner-v1.0.0.zip`** с исходным кодом и `disk_scanner.pyw`. Этот архив разрешено прикреплять к GitHub Releases.

### Способ 2: Сборка в один автономный `.exe`

Если вы хотите выложить релиз в виде отдельного исполняемого файла (чтобы у пользователей работал сканер даже без установленного Python):

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name StorageScanner disk_scanner.py
```

Готовый файл `StorageScanner.exe` появится в папке `dist/`, и его можно прикреплять к релизу.

## Частые вопросы (FAQ)

#### Почему сканер насчитал ~920 ГБ, если диск на 1 ТБ?

Сканер считает **реальный размер существующих файлов**, а не объём «железки».

- Полный объём диска: ~1000 ГБ (в Windows отображается как ~930–952 ГБ из-за пересчета 1024 байт).
- Сканер нашел **520 ГБ файлов** — это и есть то, что сейчас физически занято программами, играми и системой.
- Оставшиеся ~430 ГБ — это **ваше свободное место**, на котором пока ничего нет.

#### Почему количество занятого места в сканере чуть меньше, чем в свойствах диска в Windows?

Есть системные области Windows, куда закрыт доступ даже администратору:

- `System Volume Information` (точки восстановления системы и теневые копии).
- Служебные файлы вроде `pagefile.sys` (файл подкачки) или `$Recycle.Bin` (Корзина).

Сканер аккуратно пропускает такие системные зоны без падений и сбоев, честно увеличивая счётчик «Пропущено (ошибки доступа)».
